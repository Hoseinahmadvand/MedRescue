# 🫀 MedRescue 3D
### آزمایشگاه تعاملی ECG و شبیه‌ساز اورژانس پیش‌بیمارستانی

**MedRescue 3D** یک پلتفرم آموزشی تعاملی برای یادگیری و تمرین تحلیل ریتم‌های قلبی، تفسیر ECG، تصمیم‌گیری در شرایط اورژانسی و آشنایی با اقدامات احیای قلبی‌ریوی است.

این پروژه با استفاده از HTML، CSS، JavaScript و Three.js توسعه داده شده و بدون نیاز به Backend یا پایگاه داده قابل اجراست.

## ✨ امکانات اصلی

### 🫀 ۱. آزمایشگاه تعاملی قلب و ECG
- مدل سه‌بعدی قلب با قابلیت چرخش و بزرگ‌نمایی
- نمایش ECG زنده در قالب ۱۲ لید
- پشتیبانی از سرعت‌های 12.5، 25 و 50 mm/s
- تنظیم Gain در مقادیر 5، 10 و 20
- شبیه‌سازی آرتیفکت‌ها و تغییرات ریتم
- امکان مشاهده و ذخیره نوارهای ECG به‌صورت PNG
- پشتیبانی از ۱۵ ریتم قلبی
- نمایش مستقل وضعیت همودینامیک و علائم حیاتی
- صدای مانیتور و آلارم‌های مربوطه

### ⚡ ۲. دفیبریلاتور و پیس‌میکر
- شبیه‌سازی مراحل شارژ، اعلام تخلیه و شوک
- شوک غیرهمزمان و حالت SYNC
- شبیه‌سازی Pacing ترانس‌کوتانئوس
- نمایش اسپایک و Capture
- الگوهای آموزشی تغییرات ST در نمای ۱۲ لید

### 🚑 ۳. شبیه‌ساز اورژانس پیش‌بیمارستانی
دارای ۷ سناریوی شاخه‌ای و تعاملی:

- Ventricular Fibrillation (VF)
- Asystole
- Pulseless Electrical Activity (PEA)
- Ventricular Tachycardia (VT)
- Bradycardia
- Acute Coronary Syndrome (ACS)
- Supraventricular Tachycardia (SVT)

امکانات سناریوها:
- تصمیم‌گیری مرحله‌به‌مرحله
- ارزیابی عملکرد و اقدامات
- تایمر مأموریت
- مترونوم CPR با سرعت ۱۱۰ ضربه در دقیقه
- اندازه‌گیری ریتم فشردن قفسه سینه با Space
- چرخه‌های دو دقیقه‌ای CPR
- ثبت خط زمانی اقدامات
- محاسبه شاخص‌های عملکرد CPR
- تهیه گزارش قابل چاپ و PDF

### 📊 ۴. مقایسه ریتم‌های قلبی
- نمایش هم‌زمان دو نوار ECG
- مقایسه ویژگی‌های ریتم‌ها
- جدول تفاوت‌ها
- ابزار اندازه‌گیری زنده

### 📝 ۵. آزمون و ارزیابی
بخش آزمون شامل موضوعات زیر است:

- تشخیص ریتم از روی ECG
- تشخیص و مدیریت ایست قلبی
- تفسیر نوار قلب
- تصمیم‌گیری بالینی

ویژگی‌ها:
- سه سطح دشواری
- آزمون زمان‌دار
- تحلیل پاسخ‌های اشتباه
- ذخیره تاریخچه و نتایج آزمون

### 📚 ۶. راهنمای بالینی
- ۱۱ مبحث آموزشی
- نمودارهای مرتبط
- منابع مطالعاتی

### 📈 ۷. داشبورد آموزشی
- نمایش میزان پیشرفت
- میانگین نمرات آزمون
- آخرین فعالیت‌ها
- پیشنهاد تمرین بعدی
- ذخیره اطلاعات پیشرفت در LocalStorage

## 🎨 طراحی رابط کاربری

نسخه 1.2 با تمرکز بر تجربه کاربری و خوانایی بازطراحی شده است.

ویژگی‌های طراحی:
- رابط کاربری مدرن و واکنش‌گرا
- هدر افقی نیمه‌شفاف
- کتابخانه ریتم با دسته‌بندی رنگی
- مانیتور ECG با قاب اختصاصی
- کارت‌های علائم حیاتی با نمایش واحد و وضعیت
- پنل‌های اطلاعاتی با ساختار سلسله‌مراتبی
- پالت رنگی تیره با تأکید بر رنگ‌های فیروزه‌ای و آبی

پالت اصلی:

| کاربرد | رنگ |
|---|---|
| پس‌زمینه اصلی | `#08131F` |
| پس‌زمینه ثانویه | `#101F2E` |
| پنل‌ها | `#172B3D` |
| سطوح بالاتر | `#1C3448` |
| رنگ تأکیدی | `#35D6B0` |
| رنگ مکمل | `#78B7FF` |

در بازطراحی رابط کاربری، منطق اصلی برنامه حفظ شده است.

## ▶️ راه‌اندازی پروژه

به دلیل استفاده از JavaScript ES Modules، پروژه باید از طریق یک سرور محلی اجرا شود.

ابتدا وارد پوشه پروژه شوید:

```bash
cd MedRescue3D
```

روش اول: استفاده از Python

```bash
python3 -m http.server 8080
```

سپس آدرس زیر را در مرورگر باز کنید:

```text
http://localhost:8080
```

روش دوم: استفاده از Node.js

```bash
npx serve .
```

پس از اجرا، آدرس محلی نمایش‌داده‌شده توسط سرور را باز کنید.

## 🧬 مدل سه‌بعدی قلب و مجوز استفاده

مدل قلب موجود در مسیر زیر قرار دارد:

```text
assets/models/heart.glb
```

این مدل بر اساس پروژه BodyParts3D ساخته شده است.

اطلاعات مجوز:

- © 2008 Life Science Integrated Database Center
- License: CC BY-SA 2.1 Japan
- فایل اطلاعات مجوز: `assets/models/LICENSE-heart.txt`

این فایل مشتق‌شده باید مطابق شرایط مجوز اصلی منتشر شود.

برای استفاده از مدل جایگزین می‌توان مقدار زیر را در `data/config.json` تنظیم کرد:

```json
{
  "heartModel": false
}
```

## ⚠️ محدودیت‌های فنی و آموزشی

برای شفافیت درباره ماهیت شبیه‌ساز، محدودیت‌های فعلی آن عبارت‌اند از:

- نوارهای ECG به‌صورت مصنوعی تولید می‌شوند و از داده‌های واقعی بیماران نیستند.
- تغییرات ST و ایسکمی و محور واقعی قلب به‌صورت کامل و بالینی شبیه‌سازی نشده‌اند.
- حفره‌های مدل واقعی قلب مش‌های جداگانه ندارند؛ بنابراین حرکت دهلیز و بطن با تغییر شکل تقریبی یک مش نمایش داده می‌شود.
- مدل معتبر برون‌ده قلبی پیاده‌سازی نشده است.
- نتایج شوک در شبیه‌ساز ساده‌سازی شده‌اند و لزوماً منعکس‌کننده نتیجه واقعی درمان نیستند.
- دوز دارویی در برنامه درج نشده است.
- سناریوها، سؤالات و محتوای راهنما پیش از استفاده رسمی باید توسط متخصص فوریت‌های پزشکی بازبینی شوند.

**MedRescue 3D یک ابزار آموزشی است و جایگزین آموزش عملی، قضاوت بالینی، پروتکل‌های مصوب یا دستور پزشک نیست.**
